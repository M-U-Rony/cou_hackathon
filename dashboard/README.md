# FairPrice BD ড্যাশবোর্ড (React প্রোটোটাইপ)

**চূড়ান্ত অ্যাপ: `index.html`** (A-র গভীরতা + B-র সহজ ভাষা)
- ডেস্কটপ (৯০০px+): বাঁয়ে পণ্যের তালিকা, ডানে বিস্তারিত: দাম, "হওয়ার কথা ছিল", রায়, বাংলা সারাংশ (কপি বাটন), সীমার চার্ট, "কেন এই দাম" + টাকার পুরো হিসাব, মডেলের নির্ভরযোগ্যতা, অতীতের ঘটনা আর রিপ্লের লিংক
- মোবাইল: দর-বোর্ডের মতো তালিকা, ট্যাপ করলে একই বিস্তারিত (টাকার হিসাব ভাঁজ করা)
- URL-এর # দিয়ে পণ্য বেছে নেওয়া যায় (`#egg-farm`), তাই লিংক শেয়ার করা যায়
- সব জায়গায় একই চারটা রায়: ঠিক আছে / একটু বেশি / অনেক বেশি / স্বাভাবিকের চেয়ে কম
- `replay.html` পিচের জন্য আলাদা থাকে, অ্যাপ থেকে লিংক করা

পুরোনো প্রোটোটাইপগুলো (`prototypes.html` থেকে খোলা যায়):

| পেজ | কার জন্য | কী |
|---|---|---|
| `monitor.html` | বিচারক, সাংবাদিক, সরকারি কর্মকর্তা | পণ্যের তালিকা, দাম বনাম সীমা (৩ মাস/১ বছর/সব), waterfall, মডেল বনাম সাধারণ পদ্ধতি, অতীতের ঘটনার lead time |
| `today.html` | সাধারণ ক্রেতা (মোবাইল) | বাজারের দর-বোর্ডের মতো; সহজ ভাষায় "ঠিক আছে / একটু বেশি / অনেক বেশি", ট্যাপ করলে কারণ |
| `replay.html` | পিচের ডেমো (প্রজেক্টর) | ঘটনা দিন ধরে চালানো; সংকেতের বাতি, প্রথম সংকেত বনাম পিক। স্পেস = চালু/বন্ধ, তীরচিহ্ন = এক দিন |

## চালানো

```bash
# রিপোর মূল ফোল্ডারে আগে মডেল আর এক্সপোর্ট চালাও
python modeling/train_quantile.py
python modeling/export_dashboard.py

cd dashboard
npm install
npm run data      # reports/dashboard/fairprice_data.json কপি করে public/-এ
npm run dev       # http://localhost:5173/monitor.html ইত্যাদি
npm run build     # dist/
```

চার্টগুলো `src/lib/charts.tsx`-এ সাধারণ SVG দিয়ে বানানো (কোনো চার্ট লাইব্রেরি নেই), রং আসে প্রতিটা পেজের CSS variable থেকে।


## ঐচ্ছিক AI ফিচার (key দিলে চালু হয়)

| ফিচার | key ছাড়া | key দিলে |
|---|---|---|
| শুনুন | ব্রাউজারের নিজের বাংলা ভয়েস (Android Chrome-এ সাধারণত থাকে) | ElevenLabs ভয়েস (`eleven_v3`, বাংলা সমর্থন করে) |
| AI দিয়ে আরও সহজ করে | বাটন দেখায় না; মডেলের টেমপ্লেট লেখা থাকে | Claude (ডিফল্ট `claude-haiku-5-5`) ২–৩ বাক্যে সহজ বাংলা সারাংশ লেখে |

- Key বসাতে `.env.example` কপি করে `.env.local` বানাও (লোকাল), বা Vercel-এর Environment Variables-এ দাও। Key কখনো ব্রাউজারে যায় না, শুধু `api/` ফাংশনে থাকে
- ফাংশনগুলো (`api/summary.ts`, `api/tts.ts`, `api/health.ts`) ব্রাউজার থেকে কোনো লেখা নেয় না, শুধু পণ্য আর তারিখ নেয়, তারপর অ্যাপের নিজের ডেটা থেকে তথ্য বের করে। তাই কেউ তোমার key দিয়ে অন্য কাজ করাতে পারবে না। প্রতি IP মিনিটে ২০টা (ভয়েস ১০টা) অনুরোধের সীমা আছে
- **নম্বর-গার্ড:** AI-র লেখায় এমন কোনো সংখ্যা থাকলে যা তথ্যে নেই, লেখাটা বাতিল হয়ে টেমপ্লেট দেখায়। LLM শুধু ভাষা লেখে, সিদ্ধান্ত বা সংখ্যা দেয় না
- লোকালে `npm run dev`-এ `/api` Vite-এর ভেতর থেকেই চলে (vite.config.ts-এর `devApi`)

## বাজার তুলনা আর পাইকারি-খুচরা ব্যবধান

`python pipeline/build_markets.py` (প্রথমবার HDX ফাইলের পথ দিয়ে) → `data/processed/markets.json`, যা `export_dashboard.py` অ্যাপের ডেটায় যোগ করে।
- **ঢাকা বনাম কুমিল্লা বনাম সারা দেশ:** WFP-র মাসিক খুচরা দর (সেপ্টে ২০২৪ – জুলাই ২০২৬)। কাঁচা মরিচ, ডিম, আমদানি পেঁয়াজ। তিনটা লাইনই WFP থেকে, যাতে তুলনা একই মাপে হয়
- **পাইকারি থেকে খুচরা:** AgriPriceBD-র ঢাকার দৈনিক দাম, শুধু কাঁচা মরিচ, জুলাই ২০২০ – জুন ২০২৫। খুচরা ÷ পাইকারি অনুপাত আগের এক বছরের ৯০তম শতাংশের উপরে গেলে অস্বাভাবিক

## ফ্রন্টএন্ড

React 19 + TypeScript + Vite। কোনো UI বা চার্ট লাইব্রেরি নেই: চার্ট `src/lib/charts.tsx`-এ হাতে লেখা SVG, স্টাইল সাধারণ CSS (CSS variables দিয়ে লাইট/ডার্ক থিম)। ফন্ট Google Fonts থেকে Anek Bangla, Galada আর Tiro Bangla।
